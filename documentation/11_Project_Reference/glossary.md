# AgriCare AI — Glossary of Terms

## 1. Technical Terms
- **Inference**: The process of running new input data (a leaf photo) through a trained deep learning neural network to calculate class probabilities.
- **MobileNetV2**: A lightweight convolutional neural network architecture engineered by Google for on-device mobile vision tasks using inverted residuals and depthwise separable convolutions.
- **TensorFlow Lite (TFLite)**: A lightweight, cross-platform runtime for deploying machine learning models on edge devices like mobile phones.
- **Quantization**: A technique used to compress neural network weights and activations (e.g., from 32-bit floating point to 8-bit integers) to reduce memory consumption and accelerate execution.
- **Softmax Activation**: A mathematical function that converts unnormalized logit vectors into a normalized probability distribution summing to 1.0.
- **Row Level Security (RLS)**: A PostgreSQL security feature that controls read, insert, update, and delete access at the individual row level based on the executing user's authentication identity (`auth.uid()`).
- **Riverpod**: A reactive, compile-time safe state management framework for Flutter that decouples business logic from the widget tree.

## 2. Agricultural & Pathological Terms
- **Foliar Disease**: A plant infection primarily affecting leaves and green photosynthetic tissue.
- **Blight**: A rapid, extensive discoloration, withering, and death of plant tissues (e.g., Early Blight caused by *Alternaria solani*, Late Blight caused by *Phytophthora infestans*).
- **Canker**: A localized sunken, necrotic lesion on stems, twigs, or leaves often accompanied by gum exudation (e.g., Bacterial Canker in mango).
- **Anthracnose**: A fungal disease causing dark, sunken necrotic lesions on leaves, stems, or fruits (e.g., *Colletotrichum gloeosporioides*).
- **Leaf Smut**: A fungal infection causing small, raised, angular black spots containing fungal spores (e.g., *Entyloma oryzae* in rice).
- **Active Ingredient (a.i.)**: The specific chemical or biological compound in a commercial pesticide product that kills or inhibits the target pathogen (e.g., Mancozeb, Copper Oxychloride).
- **Pre-Harvest Interval (PHI)**: The mandatory minimum number of days that must elapse between the last pesticide application and the harvesting of crops for consumption.
- **Integrated Pest Management (IPM)**: An ecosystem-based agricultural strategy that combines cultural, biological, and targeted chemical tactics to manage plant pests and diseases sustainably.
